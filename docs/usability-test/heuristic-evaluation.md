## 十項可用性原則（Nielsen）

| 原則 | 在報告系統中的例子 |
| --- | --- |
| 系統狀態可見性 | 一眼看出報告是否完成、是否已有影像 |
| 系統與真實世界一致 | 用醫師熟悉的詞彙與工作順序 |
| 使用者控制與自由 | 已認證的報告可以取消認證、回到未完成 |
| 一致性與標準 | 同樣的狀態在每個畫面用同樣的方式呈現；以對方的設計系統為標準 |
| 錯誤預防 | 避免把報告存到錯的病人 |
| 辨識優於回憶 | 功能放在畫面上，而不是藏在選單裡 |
| 使用彈性與效率 | 儲存後直接跳下一筆、快捷鍵 |
| 美學與極簡設計 | 畫面只放醫師需要的資訊 |
| 協助使用者辨識並從錯誤中恢復 | 出錯時清楚說明原因與解決方法 |
| 說明與文件 | 需要時找得到操作說明 |
