# 使用說明

這個 repo 是課程範本。請點「Use this template」建立你自己的 repo，設為公開，之後三週的雛型與設計文件都放在這裡。

## 檔案說明

| 檔案或資料夾 | 用途 | 使用時間 |
| --- | --- | --- |
| `index.html` | 預設頁面，用來確認發布成功；之後換成你的雛型 | 第一週作業 |
| `data/` | 模擬檢查資料與片語範例 | 全程 |
| `images/` | 影像示意圖 | 全程 |
| `tokens.css`、`design-system.md` | 設計系統起始範本 | 第一週作業起 |
| `README.md` | 你的設計文件，每週依進度填寫 | 全程 |
| `docs/ai-log.md` | AI協作日誌 | 全程 |
| `docs/publish.md` | 發布到 GitHub Pages 的步驟 | 第一週作業 |
| `docs/usability-test/` | 啟發式評估紀錄表、測試腳本範本、觀察紀錄表 | 第二、三週 |

## 每週要用到的檔案

**第一週作業**：依 `docs/publish.md` 發布雛型；完成 `tokens.css` 與 `design-system.md`；填寫 `README.md` 的使用者研究、需求矛盾與設計範圍；開始記錄 `docs/ai-log.md`。

**第二週**：課堂上用 `docs/usability-test/heuristic-evaluation.md` 互評；作業用 `docs/usability-test/test-script-template.md` 準備測試腳本；更新 `README.md` 的設計變數與設計演進。

**第三週**：課堂上用 `docs/usability-test/observation-record.md` 記錄測試；完成 `README.md` 的「可用性測試後的修改」。

## 上傳新版本

在 repo 頁面點「Add file → Upload files」，上傳同名檔案就會覆蓋舊版本。GitHub Pages 會在幾分鐘內自動更新。每次上傳前，記得先截圖保存目前的版本。
